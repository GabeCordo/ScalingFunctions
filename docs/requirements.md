# Requirements

This markdown file acts as a reference for the requirements of the Yule Framework.

## Functional Requirements

1. The **Branch** shall describe a series of functions executed in order of definition.
2. The **Branch** shall allow the developer to define a function step using the builder pattern.
3. The **Metadata** shall be built using one to many branch structures.
4. The **Runnable** shall be built using one metadata structure.
5. The **Runnable** shall represent an instance of pipeline execution.
